# ScholarPath Africa

A single-page directory of international scholarships open to African students — fully funded, partially funded and tuition-free — from BSc to PhD, with requirements and links to each official site.

## Run it
Open `index.html` in any browser. No build step.

## Host it
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root.
- **Netlify Drop:** drag this folder onto https://app.netlify.com/drop.

## Update scholarships
All entries live in the `S` array inside `index.html`. Copy an entry and edit its fields.
